# 远程音频局域网测试包使用说明

测试包模拟 Agent 一侧，供收音/放音设备开发人员在不启动 Agent、模型、ASR 和 Router 的情况下验证 `remote-audio.v1`。

## 启动

```bash
cd /data/structure
/data/env310/bin/python -m agents.RemoteAudio.testkit \
  --bind 0.0.0.0 \
  --port 9876 \
  --operation all \
  --output-dir ./remote-audio-results
```

然后令设备连接 `ws://<测试机局域网IP>:9876/ws`。`--bind` 和 `--port` 均可修改。

可选操作：

```text
--operation speak
--operation record
--operation speak_and_record
--operation all
```

`--text` 可修改测试播报内容。本机存在 espeak-ng 时使用本地 TTS；否则自动生成可听见的 WAV 测试音，不依赖 Agent。

## 输出与验收

- `record_<operation_id>.wav`：record 测试收到并拼合的音频。
- `speak_and_record_<operation_id>.wav`：组合操作收到的音频。
- `report_<timestamp>.json`：完整双向消息、时间、操作 ID、时长和结果。

验收条件：

1. 三个操作均出现 `PASS`；
2. speak 的音频片按序且首尾标记唯一；
3. `playback.completed` 是物理播放完成而非接收完成；
4. record 收到 `record.stop` 后刷新尾片并回传 `record.completed`；
5. 组合操作的 `record.started` 不早于 `playback.completed`；
6. 输出 WAV 可正常播放，内容连续且没有重复片段；
7. 所有回执携带当前 UUID，不能使用上一个操作的 ID。

测试服务一次只接受一个设备。完成所选测试后会写入报告并退出，下一轮测试重新启动即可。
